# Theme Toggle Added

I have added a Dark/Light theme toggle button to the top of the Sidebar (next to "DESK CRM").

- It uses the **Sun** icon for Dark mode (to switch to Light) and **Moon** icon for Light mode (to switch to Dark).
- It leverages your existing `ThemeContext`.

## Reminder: Install Dependencies
If the icons don't show up or the app crashes, ensure you have installed the required packages:

```bash
npm install lucide-react-native react-native-svg
```

And restart the server:
```bash
npx expo start --clear
```
